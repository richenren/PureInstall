# PureInstall 产品需求文档（V0.1）

## 1. 产品定位

PureInstall 是一款面向 Windows 10/11 的轻量级纯净软件安装与管理工具，主要供自己、家人和朋友使用。

产品不做杀毒、不做实时防护、不常驻后台，也不试图替代系统安全软件。它只解决两个核心问题：

1. 从可信来源快速安装一批经过筛选的常用软件。
2. 在需要时扫描当前电脑已经安装的软件，帮助用户了解“电脑里到底装了什么”。

核心原则：**纯净、透明、无广告、无捆绑、用完即走。**

---

## 2. 目标用户

### 2.1 主要用户

- 自己：用于新电脑装机、重装系统后的软件恢复。
- 家人：不熟悉软件下载渠道，希望减少误装第三方下载器、推广软件和捆绑软件。
- 朋友：需要快速安装常用软件，或希望检查当前电脑已有软件。

### 2.2 典型场景

- 新电脑第一次装机，一次性安装浏览器、压缩工具、播放器、文本工具等常用软件。
- 重装系统后，通过一个装机清单快速恢复常用软件。
- 朋友电脑变慢或桌面软件异常增多时，打开 PureInstall 扫描当前已安装软件。
- 将软件清单导出后交给 AI 工具进行进一步分析和人工判断。

---

## 3. 产品原则

1. **不常驻**：关闭应用后不保留后台服务、托盘进程或计划任务。
2. **不自启动**：不创建 Windows 开机启动项。
3. **只读优先**：软件扫描默认只读取系统信息，不修改注册表、不删除文件。
4. **显式操作**：安装软件必须由用户主动选择并确认。
5. **可信来源**：优先通过 Windows Package Manager（winget）安装，并维护人工精选的软件列表。
6. **不广告化**：不做竞价排名、不插入推广软件、不通过下载器二次包装安装包。
7. **不自动清理**：V0.1 不自动判断或删除“垃圾软件”，避免误删正常软件。
8. **本地优先**：V0.1 不要求账号、云端服务或数据上传。

## 4. V0.1 功能范围

### 4.1 精选软件库（P0）

展示人工筛选的软件目录，每个软件至少包含：

- 软件名称
- 分类
- 简短描述
- winget Package ID
- 官方主页
- 用于匹配已安装软件的名称别名

支持：

- 按分类筛选
- 按名称/描述搜索
- 多选软件
- 显示是否已检测到安装

### 4.2 单个安装与批量安装（P0）

安装流程：

1. 启动时检查 winget 是否可用。
2. 用户选择一个或多个软件。
3. 用户点击“安装所选”。
4. PureInstall 按顺序调用 winget 安装。
5. 每个软件展示等待中、安装中、成功、失败状态。
6. 批量安装完成后重新扫描本机软件列表。

推荐安装命令：

```text
winget install --id <PACKAGE_ID> --exact --source winget --accept-source-agreements --accept-package-agreements --disable-interactivity
```

说明：

- winget 负责获取包清单及安装程序。
- 安装程序如果需要 UAC 或自身交互，由 Windows/安装程序正常处理。
- PureInstall 不尝试绕过安全软件、UAC 或系统权限控制。

### 4.3 已安装软件扫描（P0）

应用打开时可主动扫描当前电脑已经安装的软件，包括 PureInstall 安装之前存在的软件。

V0.1 读取以下注册表位置：

- `HKLM\\SOFTWARE\\Microsoft\\Windows\\CurrentVersion\\Uninstall`
- `HKLM\\SOFTWARE\\WOW6432Node\\Microsoft\\Windows\\CurrentVersion\\Uninstall`
- `HKCU\\SOFTWARE\\Microsoft\\Windows\\CurrentVersion\\Uninstall`

展示字段：

- 名称
- 版本
- 发行商
- 安装日期（若系统有记录）
- 卸载命令是否存在（不直接展示完整命令）

要求：

- 扫描操作只读。
- 对重复记录进行去重。
- 不使用 `Win32_Product` 做全量扫描，避免触发 MSI 修复/一致性检查。
- 扫描失败不能影响软件安装主功能。

### 4.4 已安装状态匹配（P0）

将精选软件库中的软件与扫描结果进行名称匹配。

V0.1 使用软件名称 + aliases 的简单规则判断是否已安装。

匹配失败时只显示“未检测到”，不能声明软件一定未安装。

### 4.5 装机清单导出/导入（P0）

用户可将当前选择的软件导出为 JSON 清单。

格式：

```json
{
  "version": 1,
  "appIds": ["7zip", "vlc", "vscode"]
}
```

支持：

- 导出当前选择
- 从本地导入清单
- 忽略清单中当前版本软件库不存在的 ID

用途：

- 自己重装系统后复用
- 发给朋友一键选择同一批软件

### 4.6 已安装软件列表（P0）

提供独立页面查看全部扫描到的软件。

支持：

- 名称搜索
- 显示版本/发行商/安装日期
- 手动重新扫描

V0.1 不提供强制卸载、注册表删除和目录删除功能。

## 5. 后续版本（非 V0.1）

### 5.1 软件变化快照（P1）

每次手动扫描可选择保存快照，下次扫描时展示：

- 新增软件
- 已移除软件
- 版本变化

该功能不要求后台常驻。

### 5.2 AI 体检报告（P1）

导出经过脱敏的 Markdown/JSON 报告，包括：

- 已安装软件
- 开机启动项
- 非系统计划任务
- 基础系统信息

报告可交给 ChatGPT、豆包、WorkBuddy 等 AI 工具进行人工辅助分析。

AI 只负责解释和分类，默认不自动删除软件。

### 5.3 软件卸载入口（P1）

在明确验证后，可增加调用系统正常卸载流程的入口。

禁止通过直接删除软件目录模拟卸载。

## 6. 非功能需求

### 6.1 兼容性

- Windows 10 及 Windows 11。
- 优先支持 x64。
- winget 不可用时仍允许查看软件库和扫描已安装软件，但禁用安装按钮并给出提示。

### 6.2 性能

- 应用冷启动后尽快展示主界面，扫描在界面加载后执行。
- 已安装软件扫描目标：常见个人电脑上 2 秒内完成。
- 不运行后台守护进程。

### 6.3 安全

- 不申请管理员权限进行普通扫描。
- 不关闭或规避 Defender、火绒、360 等安全产品。
- 不注入其他进程。
- 不监控键盘、浏览器内容或私人文件。
- 不执行来源不明的 PowerShell 脚本。
- 所有安装行为由用户点击触发。

### 6.4 隐私

- V0.1 不上传已安装软件清单。
- 不采集设备标识、账号、文件列表等与核心功能无关的信息。

## 7. 技术方案

### 7.1 桌面框架

- Tauri 2
- Vue 3
- TypeScript
- Vite

### 7.2 本地系统能力

Rust/Tauri Commands 提供：

- `check_winget`
- `scan_installed_apps`
- `install_app`

前端不直接执行任意 shell 命令。

### 7.3 软件目录

V0.1 使用静态 JSON：

`src/data/apps.json`

后续可改为 GitHub 托管的软件目录，但仍保持客户端本地可用。

---

## 8. V0.1 验收标准

满足以下条件即可认为第一版完成：

1. Windows 10/11 上应用可启动。
2. 无后台常驻服务、无开机自启动项。
3. 首页可以浏览、搜索和筛选精选软件。
4. 能检测 winget 是否可用。
5. 能扫描 PureInstall 安装前已经存在的常规桌面软件。
6. 精选软件能够显示“已检测安装/未检测到”状态。
7. 能选择多个软件并按顺序调用 winget 安装。
8. 每个安装任务能够展示成功或失败结果。
9. 能导出/导入装机清单。
10. 已安装软件页面可以搜索并手动重新扫描。
11. 扫描过程不修改注册表、不删除文件。
12. 应用本身不包含广告、推广位和第三方捆绑软件。
